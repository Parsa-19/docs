### Ubuntu container
launching a container using the latest Ubuntu Linux base image:<br>
`docker container run --rm -ti docker.io/ubuntu:latest /bin/bash`
> **docker container run** is functionally same as **docker run**

### Fedora container
launch a container using the latest Fedora Linux base image:<br>
`docker container run --rm -ti docker.io/fedora:latest /bin/bash`

### Alpine container
launching a container using the latest Alpine Linux base image:<br>
`docker container run --rm -ti docker.io/alpine:latest /bin/sh`
